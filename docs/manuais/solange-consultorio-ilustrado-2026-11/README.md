# Manual ilustrado do Solange Consultório (10/11/2026)

Manual operacional com 39 páginas, 37 procedimentos, prints reais do ambiente de demonstração autenticado (dados sintéticos) e de testes isolados da versão candidata das etiquetas Link 9027.

O PDF está em `Manual_Ilustrado_Solange_Consultorio_2026-11-10.pdf`.
A versão HTML e os arquivos `assets/*.png` permitem conferir a procedência das capturas. O script `make_manual.py` gera o HTML a partir das imagens já existentes e de textos estáticos.

**Atenção:** o consultório permanece em pré-homologação para dados reais. O módulo público antigo de etiquetas não exige autenticação até a migração segura, portanto não deve receber nomes reais. O manual documenta a UI conforme os ambientes de teste em 10/11/2026. O prontuário clínico não foi capturado por sigilo.

O material deve ser atualizado após publicação do SHA homologado. Issue #333. PR de integração das etiquetas: #332.
