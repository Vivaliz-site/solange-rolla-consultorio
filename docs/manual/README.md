# Manual operacional ilustrado do Consultório Solange Rolla

**Arquivo:** [Manual operacional ilustrado (PDF)](Manual_Operacional_Ilustrado_Solange_Consultorio.pdf)

**Versão:** 2.0 — 10/11/2026

**Escopo:** 27 capítulos, 55 procedimentos, 226 passos e 28 inserções de prints (17 fontes visuais distintas). As quatro primeiras rotinas explicam etiquetas Link 9027; depois são cobertos acesso, Dashboard, pacientes, cadastro e ficha, agenda e reagendamento, confirmação/cancelamento, atendimento/prontuário, formulários e assinatura, eventos e inscrições, financeiro, contas a pagar, fiscal mock, relatórios, usuários, segurança, e checklist de rotina.

**Proveniência:** screenshots reais geradas a partir de navegador Chromium no ambiente client demo da VM canônica, e da interface candidata das etiquetas em testes isolados. As capturas de identificação de pessoa foram borradas para evitar exposição; formulários de login foram fotografados vazios e QR/códigos de MFA não são publicados. Não são screenshots da implantação pública final.

**Segurança e exatidão:** este é manual de referência para o sistema no código/demonstração. O consultório continua NO-GO para dados reais até que gates de deploy/homologação sejam satisfeitos. A aplicação provisória de etiquetas em https://shopvivaliz.com.br/validacao/etiquetas-solange/ continua sem autenticação. Não usar dados reais de pacientes ali. A integração protegida em /etiquetas está em revisão na PR #332.

**Autorizações:** o manual não contém senha, token ou dados clínicos reais. URLs de preview locais de VM não foram compartilhadas.

**Documentação técnica e mudanças:** [Issue #334](https://github.com/Vivaliz-site/solange-rolla-consultorio/issues/334).
